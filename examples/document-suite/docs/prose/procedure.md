**Preparation**

1. Identify the test item and freeze its configuration.
2. Connect a calibrated input source and an independent timing instrument.
3. Record the configured temperature limit and timing uncertainty.

**Execution**

1. Establish an input below the configured limit.
2. Step the input above the limit and record the transition time.
3. Record the first visible alarm time and calculate elapsed time in seconds.
4. Retain the raw observations and any deviations from this procedure.

**Acceptance**

The elapsed time must be no greater than two seconds. The reviewer must account for
measurement uncertainty and confirm the tested configuration before accepting a result.
Doc42 publishes this authored procedure; it does not execute or evaluate it.
