# Runnable examples

Use the [first-PDF guide](getting-started.md) to build without an external domain library.
Keep the examples, binary, and documentation versions together.

| Example | Output and purpose |
| --- | --- |
| `examples/first-document` | FIRST-001.pdf: a minimal document with two prose sections |
| `examples/document-suite` | Four temperature-monitor documents: CRS, SRS, test and verification |
| `examples/drone-srs` | DRN-SRS-001.pdf: requirements tables and model-backed diagrams |
| `examples/house-template` | Customize logo, colors and typography |

Review the PDFs generated by its release build:
[first document](https://github.com/elan8/doc42-release/releases/download/v0.8.1/FIRST-001.pdf),
[drone SRS](https://github.com/elan8/doc42-release/releases/download/v0.8.1/DRN-SRS-001.pdf),
and the monitor suite's
[CRS](https://github.com/elan8/doc42-release/releases/download/v0.8.1/MON-CRS-001.pdf),
[SRS](https://github.com/elan8/doc42-release/releases/download/v0.8.1/MON-SRS-001.pdf),
[test specification](https://github.com/elan8/doc42-release/releases/download/v0.8.1/MON-TEST-001.pdf),
and [verification report](https://github.com/elan8/doc42-release/releases/download/v0.8.1/MON-VR-001.pdf).

```sh
doc42 build examples/document-suite --all --out out
doc42 build examples/drone-srs --out out
```

The suite's verification report is authored content, not executed evidence or an
automatic verdict. See [templates](templates.md) to change the presentation and
[authoring](authoring.md) to change the document structure.
