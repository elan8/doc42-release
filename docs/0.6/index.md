# Doc42 documentation

Doc42 composes engineering documents from SysML v2 views and renders them as PDF.

- [Getting started](getting-started.md): install Doc42 and build the sample documents.
- [Authoring documents](authoring.md): metadata, sections, text, model values, tables and figures.
- [Templates](templates.md): the built-in templates, and how to make your own house template.
- [Automation and release checks](automation.md): exit codes, diagnostics, reproducibility and evidence.

The samples are in [`examples/`](../examples):

| Sample | Shows |
| --- | --- |
| [`document-suite`](../examples/document-suite) | Four documents for a small temperature monitor: customer requirements, system requirements, test specification, verification report |
| [`drone-srs`](../examples/drone-srs) | A system requirements specification with requirement tables and model-backed diagrams |
| [`house-template`](../examples/house-template) | A house template made from `elan8-standard`: logo, colours and title page |

These pages describe Doc42 0.6.0.
